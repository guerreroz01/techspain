# Demon's Souls Remake Surpasses 60 FPS on the PS5 Emulator and Approaches 120 FPS with Frame Generation

PlayStation 5 emulation continues to advance, and the *Demon's Souls* remake is once again pushing boundaries. A customized version of the PS5 emulator **KyTyPS5**, developed by chenxiao07 and specifically tuned for this title, already runs the game **above 60 FPS** on PC. The test was conducted by the channel **Geralt Benchmarks**, which ran it on a system equipped with an AMD Ryzen 7 9800X3D and an NVIDIA GeForce RTX 5070 at Quad HD (2K) resolution.

The same branch confirms that improvements were applied to the renderer, shaders, and memory management, and are intended for versions 1.05 and 1.07 of the PS5 game. It is therefore not a generic speed adjustment, but specific work on the title.

## The Progression of the PS5 Emulator: From 5 FPS to Over 60

What makes this truly newsworthy is not the isolated figure, but the pace. According to the person responsible for the tests, just weeks ago the same remake was falling **below 5 FPS** even with a GeForce RTX 5090 and the same processor. In September the title [reached 30 FPS for the first time on the emulator](/noticias/demons-souls-remake-ps5-emulator-30fps/), after the project barely managed to pass the character creation screen. Now the rate surpasses 60 FPS with a GPU that is clearly less powerful, the RTX 5070.

Part of the community attributes that jump to the use of an AI assistant in development, an explanation circulating through the emulation scene but not officially confirmed. In any case, the distance between the 5 FPS from a few weeks ago and today's figures makes clear which direction compatibility is heading.

## DLSS Frame Generation Pushes the Rate Up to 120 FPS

The tested branch also begins incorporating compatibility with NVIDIA technologies: it allows using **DLAA** and **DLSS Frame Generation 2X**, although it still **does not support DLSS Super Resolution**. Without the latter, internal resolution cannot be reduced to upscale afterward and gain performance, which is precisely the lever that would most help modest hardware systems.

With Frame Generation active, the rate rises **up to 120 FPS**, almost double the base figure. That data should be read with caution: interpolated frames are not natively rendered images, so the figure speaks of perceived smoothness, not actual rendering power. In a game like this, moreover, 120 FPS contributes less than in a competitive shooter; the value lies in that the experience stops appearing choppy.

## What Works Today and What Still Fails

Even with the figure on screen, the remake **is not perfectly emulated**: stutters, frame pacing problems, and other inconsistencies still exist. KyTyPS5 is still in an early development phase, and the branch used in the test is optimized specifically for *Demon's Souls*, not for the PS5 catalog in general. Nor is it the only recent advance from the project: a few weeks ago [Marvel's Wolverine already started on PC with this same emulator](/noticias/marvels-wolverine-arranca-en-pc-emulador-ps5/).

In its current state, the result is playable progress on a high-end PC: at 2K and with over 60 FPS, the title can be enjoyed from start to finish, far from the levels that made it unplayable a month ago. What remains pending is frame pacing stability, upscaling with DLSS Super Resolution, and a base that performs equally well outside this specific title.
