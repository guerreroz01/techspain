Microsoft ya distribuye la actualización de Windows 11 de 2026, conocida también como **Windows 11, versión 26H2**. La buena noticia es que, para la mayoría de equipos compatibles, no se trata de una reinstalación completa: el sistema la entrega como un **paquete de habilitación** (enablement package), una descarga pequeña que se instala como un parche mensual y requiere un único reinicio.

Esta guía explica qué equipos son elegibles, cómo activar la actualización desde Windows Update y qué hacer cuando el aviso todavía no aparece en tu dispositivo.

## Requisitos previos

- Un equipo que ejecute **Windows 11, versión 25H2 o 24H2**. La actualización 26H2 se ofrece como paquete de habilitación solo a dispositivos elegibles que ya estén en una de esas dos versiones.
- Conexión a internet para descargar el paquete.
- Un momento para reiniciar el equipo: el proceso pide **un solo reinicio**.

La razón de que la descarga sea pequeña es que las versiones 26H2, 25H2 y 24H2 comparten la misma rama de servicio y la misma base de código. Esto significa que buena parte de los componentes que necesita la versión 26H2 ya están presentes en el equipo antes de que la actualización se active, como explica Microsoft en su anuncio.

## Paso 1: abre Configuración y entra en Windows Update

Dirígete a **Configuración** > **Windows Update** desde el menú de inicio del sistema. Es el mismo panel que usas para las actualizaciones mensuales habituales.

## Paso 2: activa las actualizaciones anticipadas

Dentro de Windows Update, activa la opción **Obtener las últimas actualizaciones en cuanto estén disponibles**. Microsoft indica que este es el ajuste que permite recibir la versión 26H2 entre los primeros.

## Paso 3: descarga e instala Windows 11, versión 26H2

Cuando el dispositivo sea elegible, aparecerá la opción de **descargar e instalar Windows 11, versión 26H2**. Acéptala y deja que el proceso se complete: al ser un paquete de habilitación, la descarga es reducida y la instalación es rápida. El equipo solo pedirá reiniciarse una vez para pasar a la nueva versión.

## Qué hacer si la actualización todavía no aparece

Es normal que la opción no esté disponible de inmediato. Microsoft aplica un **despliegue controlado y progresivo**, así que la disponibilidad se amplía con el tiempo. Durante ese despliegue, la compañía puede aplicar **retenciones de seguridad** (safeguard holds) en equipos donde detecte un problema de compatibilidad conocido que pudiera afectar a la experiencia de actualización.

Si no ves la actualización todavía, espera a que el despliegue llegue a tu equipo y consulta el estado de la distribución en el centro de **Windows release health** (`aka.ms/WindowsReleaseHealth`), donde Microsoft publica incidencias, retenciones y avances del despliegue.

## Para equipos comerciales y educativos

Windows 11, versión 26H2 ya está disponible a través de las herramientas que las organizaciones usan para gestionar actualizaciones, como **Windows Autopatch** y el **centro de administración de Microsoft 365**. Los equipos de TI pueden seguir usando sus herramientas, anillos de actualización, directivas y prácticas de despliegue habituales.

Microsoft recomienda a los clientes comerciales y educativos empezar con **despliegues dirigidos** para validar aplicaciones, dispositivos y flujos de trabajo críticos antes de extender la actualización por toda la organización. Como nota, las descargas en el centro de administración de Microsoft 365 y canales similares pueden sufrir algún retraso.

## Cómo comprobar que la actualización se instaló

El anuncio de Microsoft no detalla un método de comprobación adicional: lo que sí confirma es que, tras completar el proceso y el único reinicio, el equipo pasa a ejecutar la **versión 26H2**. A partir de ahí, instalar esta versión **reinicia el ciclo de soporte** de las ediciones compatibles de Windows 11: 24 meses para las ediciones Home y Pro, y 36 meses para Enterprise y Education.

Además, algunas funciones y mejoras que llegaron desactivadas por defecto en la versión 25H2 pasan a estar **activadas por defecto** en la 26H2. Microsoft publica los detalles de esas novedades y la guía de planificación para profesionales en su blog de IT Pro (`aka.ms/26H2-for-IT-pros`).

## Advertencias y limitaciones

- La actualización como paquete de habilitación está pensada para dispositivos elegibles que ya usen **25H2 o 24H2**; si tu equipo está en una versión anterior, este método no aplica.
- El despliegue es gradual: que la opción no aparezca no significa que tu equipo sea incompatible, sino que la distribución aún no ha llegado o existe una retención temporal por compatibilidad.
- Mantener el equipo actualizado es la vía recomendada por Microsoft para recibir las últimas mejoras de calidad, fiabilidad y seguridad.
